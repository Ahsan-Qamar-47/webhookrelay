# WhatsApp Webhook Integration Guide

This guide details how to set up, test, and verify **WhatsApp / Meta Business Webhooks** with **WebhookRelay** during local development and production deployment.

---

## 1. Overview & Verification Protocol Flow

WhatsApp webhooks use Meta Graph API standards. Webhooks require a two-step integration model:
1. **Challenge Verification (`GET`)**: Meta sends an HTTP GET request to verify ownership of your webhook endpoint.
2. **Event Delivery (`POST`)**: Incoming messages, delivery receipts, and status updates are sent as JSON payloads signed with `X-Hub-Signature-256`.

```
+------------------+      +---------------------------+      +-----------------------+      +-------------------------+
| Meta Cloud Platform| ---> | WebhookRelay Ingest GET   | ---> | Challenge Verification| ---> | HTTP 200 (hub.challenge)|
| (WhatsApp Graph) |      | /ingest/:subdomain        |      | (hub.verify_token)    |      | Plain text response     |
+------------------+      +---------------------------+      +-----------------------+      +-------------------------+
                                       |
                                       v
                          +---------------------------+      +-----------------------+      +-------------------------+
                          | WebhookRelay Ingest POST  | ---> | WebhookRelay CLI      | ---> | Local Application Server|
                          | (Incoming Messages/Status)|      | (relay connect)       |      | http://localhost:3000   |
                          +---------------------------+      +-----------------------+      +-------------------------+
```

## 2. Task 28.1: Meta Developer Account & WhatsApp Business App Setup

1. **Meta Developer Account**:
   - Go to [Meta for Developers](https://developers.facebook.com/) and register or log in.
   - Complete developer registration and create an Organization if required.
2. **Create WhatsApp Business App**:
   - Click **My Apps > Create App**.
   - Select **Other > Business** application type.
   - Set app name (e.g. `WebhookRelay WhatsApp Test`).
   - Add the **WhatsApp** product to your app from the product catalog.
3. **Get Test Phone Number & Access Token**:
   - Navigate to **WhatsApp > API Setup** in your app dashboard.
   - Copy the temporary **System User Access Token** (`EAAG...`).
   - Note your assigned **Test Phone Number** (e.g., `+1 555-023-9876`) and **Phone Number ID**.
   - Add your personal WhatsApp phone number to the **To** recipient list for sending test messages.

---

## 3. Task 28.2: WhatsApp Webhook Configuration

1. In your Meta App Dashboard, navigate to **WhatsApp > Configuration > Webhooks**.
2. Click **Edit Webhook**.
3. Set fields:
   - **Callback URL**: Enter your WebhookRelay endpoint URL:
     ```
     http://localhost:8080/ingest/my-whatsapp-tunnel
     ```
     *(Or public server URL e.g., `https://relay.yourdomain.com/ingest/my-whatsapp-tunnel`)*
   - **Verify Token**: Custom string matching your endpoint secret configured in WebhookRelay (e.g., `my_custom_whatsapp_verify_token`).
4. **Subscribe to Webhook Fields**:
   - `messages` (Incoming user messages, text, media, location)
   - `message_status` (Sent, delivered, read status callbacks)
5. Click **Verify and Save**.

## 4. Task 28.3: WhatsApp Verification Endpoint Architecture (`GET`)

Meta sends a GET request during verification with the following query parameters:
- `hub.mode`: Set to `subscribe`.
- `hub.verify_token`: Custom verification token string.
- `hub.challenge`: Plain text token generated by Meta.

### Handling Logic in WebhookRelay (`handleIngest`):

```javascript
// Meta / WhatsApp Webhook Challenge Verification (GET request)
if (req.method === 'GET' && req.query['hub.mode'] === 'subscribe') {
  const verifyToken = req.query['hub.verify_token'];
  const challenge = req.query['hub.challenge'];

  if (endpoint.secret && verifyToken !== endpoint.secret) {
    return res.status(403).json({
      success: false,
      error: { code: 'VERIFICATION_FAILED', message: 'Verify token mismatch' },
    });
  }

  // Record verification event for inspector UI visibility
  // ...
  return res.status(200).send(challenge);
}
```

- **Per-Endpoint Verification**: In WebhookRelay, `endpoint.secret` stores your custom `verify_token`.
- **Response Format**: Returns HTTP 200 with raw text body containing `hub.challenge` as expected by Meta Graph API.

## 5. Task 28.4: Testing WhatsApp Webhook Events

### 1. Verification Test (`GET`)
Execute a verification request via cURL:

```bash
curl -X GET "http://localhost:8080/ingest/my-whatsapp-tunnel?hub.mode=subscribe&hub.verify_token=my_custom_whatsapp_verify_token&hub.challenge=CHALLENGE_STRING_123"
```
**Expected Response**: `CHALLENGE_STRING_123` with status `200 OK`.
